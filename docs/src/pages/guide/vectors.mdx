# Reproducing vectors

Everything is generated from the Python reference — no hand-written constants.

## Generate vectors

```sh
python3 ref/vdf_reference.py
```

Writes `vectors/vdf_vectors_512.json` and `vectors/vdf_vectors_2048.json`
(T = 2^16), each containing: `N`, `x`, `y`, `π`, `L`, `r` (as limb arrays),
`T`, `nonce`, `instance_hash`, and the RSW decryption fields `ctx`,
`plaintext`, `ciphertext`, `ct_hash`, `pt_hash`. `y` is the sign-canonical
output `min(y, N − y)`. `L` is the hash-to-prime challenge: the smallest
`nonce` whose candidate from `poseidon('VDF_WES_CHALLENGE_V1', instance, nonce)`
is prime — the same derivation the Cairo verifier performs in-program
(`ref/poseidon.py` is cross-checked against the Cairo builtin). The reference
asserts the RSW φ(N) shortcut equals sequential squaring, and that the
Wesolowski proof verifies, before emitting.

## Regenerate Cairo tests

```sh
python3 scripts/regen_clean_tests.py
python3 scripts/gen_arithmetic_tests.py
```

Writes `cairo/lib/src/tests.cairo` — eleven tests: modmul, the prime
challenge and `r` calculation, composite-candidate and composite-challenge
rejection, the Barrett boundary regression, mu validation, forged- and
negated-output rejection, full verification, negated-proof acceptance and
the RSW keystream roundtrip. `gen_arithmetic_tests.py` writes 31
additional tests to `arithmetic_tests.cairo`, using Python integer arithmetic
as the oracle and seed 20260907. These cover full and noncanonical operands
at 256–2048 bits and zero, sparse, dense and random exponent pairs.

## Regenerate executable arguments

```sh
python3 scripts/write_exec_args.py
```

Writes `vectors/exec_args_512.json` and `vectors/exec_args_2048.json` — the
flat felt252 input arrays for `scarb execute`, with the leading Span-length
felt. Layout:
`[N(k), mu_n(k+1), x(k), y(k), pi(k), T(2), nonce, ctx, ct_len, ct(ct_len)]`
with k = 8 or 32; the input length must match exactly. The challenge `L` and
`r` are **not** inputs; they are derived in-program, and there is no longer a
`mu_l` constant. The script prints the expected output
`[instance_hash, ctx, ct_hash, pt_hash]`.

## Validate model changes first

`ref/cairo_model_v2.py` is the exact Python mirror of the Cairo algorithm.
If you change the Cairo math:

1. Change `cairo_model_v2.py` first.
2. Run it against the vectors: `python3 ref/cairo_model_v2.py`.
3. Run differential tests against Python integers:
   `python3 -m unittest discover -s ref -p 'test_*.py' -v`.
4. Port limb-for-limb, then run `scarb execute` on the smallest vector.
