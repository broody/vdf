# Reproducing vectors

Everything is generated from the Python reference — no hand-written constants.

## Generate vectors

```sh
python3 ref/vdf_reference.py [output.json]
```

Writes an array of vectors, each containing: `N`, `x`, `y`, `π`, `L`, `r`
(as limb arrays), `T`, and the RSA parameters. `L` is the Fiat-Shamir
challenge `poseidon(N, x, y, T)` with bit 192 forced — the same derivation
the Cairo verifier performs in-program (`ref/poseidon.py` is cross-checked
against the Cairo builtin). The reference asserts the RSW φ(N) shortcut
equals sequential squaring, and that the Wesolowski proof verifies, before
emitting.

## Regenerate Cairo tests

```sh
python3 scripts/regen_clean_tests.py
python3 scripts/gen_arithmetic_tests.py
```

Writes `cairo/lib/src/tests.cairo` — unit tests for both limb domains, the
Barrett boundary regression, mu validation, plus the full-verify and
forgery-rejection tests (six tests). `gen_arithmetic_tests.py` writes 31
additional tests to `arithmetic_tests.cairo`, using Python integer arithmetic
as the oracle and seed 20260907. These cover full and noncanonical operands
at 256–2048 bits and zero, sparse, dense and random exponent pairs.

## Regenerate executable arguments

```sh
python3 scripts/write_exec_512.py
```

Writes `vectors/exec_args_512.json` — the flat felt252 input array for
`scarb execute`, with the leading Span-length felt. Layout:
`[N(8), mu_n(9), x(8), y(8), pi(8), mu_l(5), T(2)]` — the challenge `L` and
`r` are **not** inputs; they are derived in-program.

## Validate model changes first

`ref/cairo_model_v2.py` is the exact Python mirror of the Cairo algorithm.
If you change the Cairo math:

1. Change `cairo_model_v2.py` first.
2. Run it against the vectors: `python3 ref/cairo_model_v2.py`.
3. Run differential tests against Python integers:
   `python3 -m unittest discover -s ref -p 'test_*.py' -v`.
4. Port limb-for-limb, then run `scarb execute` on the smallest vector.
